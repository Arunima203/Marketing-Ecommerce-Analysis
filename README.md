# 📊 Marketing E-Commerce Data Analysis

An end-to-end data analysis project focused on understanding customer behavior, product performance, marketing campaign effectiveness, and revenue trends in an e-commerce business using Python.

## 🎯 Project Overview

This project analyzes e-commerce datasets to extract meaningful business insights and understand how customers interact with products and marketing campaigns.

The analysis uses Python libraries for data cleaning, exploration, analysis, and visualization.

## 🎯 Objectives

- Analyze customer purchasing behavior.
- Understand product and category performance.
- Evaluate marketing campaign effectiveness.
- Analyze customer engagement through events.
- Identify revenue trends across marketing channels.
- Generate meaningful business insights using data analysis.

## 📁 Datasets

The project works with five datasets:

1. **Customers:** Customer information and demographics.
2. **Products:** Product details, categories, brands, and pricing.
3. **Campaigns:** Marketing campaign information and objectives.
4. **Events:** Customer interaction and engagement events.
5. **Transactions:** Purchase details, revenue, discounts, and refunds.

**Note:** The original `events.csv` file is approximately 171 MB and is excluded from this GitHub repository because it exceeds GitHub's standard 100 MB file limit.

## 🔍 Analysis Performed

### 1. Data Inspection and Cleaning
- Dataset shape and structure inspection.
- Missing value analysis.
- Duplicate row detection and removal.
- Data type verification.
- Date conversion and extraction.

### 2. Customer Analysis
- Total customer count.
- Country-wise customer distribution.
- Gender distribution.
- Loyalty tier analysis.

### 3. Product Analysis
- Product information inspection.
- Product category and brand analysis.
- Product pricing exploration.

### 4. Marketing Campaign Analysis
- Campaign-wise revenue analysis.
- Campaign transaction analysis.
- Best-performing campaign identification.
- Revenue comparison across marketing channels.
